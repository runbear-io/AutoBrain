# Changelog

All notable changes to AutoBrain are documented here.

## 0.1.2 - 2026-09-01

- Added a Web-first local experiment setup and retrieval comparison flow.
- Added typed source readiness and local experiment lifecycle boundaries.
- Added retrieval-only evaluation as the default diagnostic mode.
- Added stricter cancellation, request-size, URL, and experiment-ID
  validation.

This release is not a recommendation-grade provider release. Live Slack,
Notion, and provider verification remain prerequisites for that claim.
